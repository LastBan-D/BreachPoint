# Unity & Git Intensive Project

Репозиторий учебного проекта в рамках интенсивного курса разработки на Unity и версионирования в Git.

## Стек технологий
* **Game Engine:** Unity LTS (Universal Render Pipeline)
* **Language:** C# (.NET Standard)
* **Version Control:** Git CLI, Git LFS
* **Target Platforms:** Standalone (Windows), WebGL

## Структура каталогов
* `Assets/_Project/Scripts/` — архитектура и логика персонажа / систем
* `Assets/_Project/Scenes/` — игровые и вспомогательные сцены
* `Assets/_Project/Prefabs/` — шаблоны объектов и Prefab Variants
